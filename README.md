# GDG Technical Quiz Platform

An interactive technical quiz application built using HTML, CSS and JavaScript.

The platform tests participants on programming, web development, Git & GitHub, APIs, general technology and Google developer tools.

## Features

- Multiple-choice technical questions
- One question displayed at a time
- Random question selection
- Randomized answer options
- 20-second countdown timer for every question
- Live score counter
- Quiz progress bar
- Final score and accuracy
- Performance feedback
- Complete answer review
- Correct answer comparison
- Local leaderboard
- Responsive design
- Restart quiz functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Quiz Topics

Questions include:

- Programming fundamentals
- Web development
- JavaScript
- Git and GitHub
- APIs
- Firebase
- Google Cloud
- Android development
- General technology

## How It Works

1. Enter your name.
2. Start the quiz.
3. Answer 15 randomly selected questions.
4. Each question has a 20-second timer.
5. Submit your selected answer.
6. View your final score and accuracy.
7. Review your answers and the correct answers.
8. Check the local leaderboard.
9. Restart the quiz for a new randomized attempt.

## Running Locally

Clone the repository and open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.
